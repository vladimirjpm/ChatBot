Что запущено прямо сейчас

# Qdrant — нужен для upload документов и RAG-поиска (этапы 4–5)
# Требует запущенный Docker Desktop
docker compose up -d qdrant
→ REST http://localhost:6333 · gRPC :6334
# Проверка
docker ps
curl.exe http://localhost:6333/collections/documents
# Стоп / снос (volume chatbot_qdrant_data сохраняется при stop/down, удаляется при down -v)
docker compose stop qdrant
docker compose down -v
# Frontend — первый раз (установка зависимостей)
cmd /c "cd C:\_Proj\ChatBot\chatbot-ui && npm install"
# Frontend — запуск
cmd /c "cd C:\_Proj\ChatBot\chatbot-ui && npm run dev"
→ http://localhost:5173
# Backend API (нужен $env:Llm__ApiKey = "sk-...")
cd C:\_Proj\ChatBot\ChatBot.Api
dotnet run
→ http://localhost:5249/openapi/v1.json · /health · /health/live
# Тесты
dotnet test

API эндпоинты

POST
/api/chat/stream
SSE-стрим ответа LLM. Body: { message, sessionId?, role?, resumeContext?, language? }
POST
/api/documents/upload
Загрузка документа (multipart/form-data, поле file) → ingestion → Qdrant. Сейчас заглушка.
GET
/openapi/v1.json
OpenAPI-схема (только Development).
GET*
/api/debug/history/{sessionId}
Запланирован — дамп ChatHistory по сессии для отладки. Только Development.
